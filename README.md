# sonicriders.info database
https://sonicriders.info

The one place for all things competitive about Sonic Riders: Tournament Edition.

This repository uses Hugo, the static site framework. To contribute, please install Hugo first: https://gohugo.io

When cloning this repository, use `git clone --recurse-submodules https://github.com/SilenttEye/SonicRidersDatabaseSite` to get the latest submodules at the same time when cloning.

If you've already cloned the repository, use `git submodule update --init --recursive`.
